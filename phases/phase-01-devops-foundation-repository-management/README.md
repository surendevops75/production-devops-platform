# Phase 01 — DevOps Foundation & Repository Management

## Overview

This phase establishes the foundation for managing a production-oriented DevOps project.

It covers GitHub organization, repository strategy, branching and pull request workflows, microservice architecture fundamentals, Docker, AWS account and infrastructure organization, IAM identity management, and Amazon ECR.

The objective is to establish a structured and maintainable foundation before moving into CI/CD automation, Kubernetes, infrastructure provisioning, and production deployment.

## Objectives

- Understand GitHub organization and repository management.
- Define an appropriate repository strategy for a microservices project.
- Follow branching and pull request practices.
- Understand microservice architecture fundamentals.
- Understand Docker and containerization.
- Organize AWS accounts and infrastructure responsibilities.
- Understand IAM users, roles, policies, and AWS identity.
- Understand Amazon ECR and container image registry management.
