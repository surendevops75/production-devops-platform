# Phase 03 — Kubernetes, EKS & Database Fundamentals

## Overview

This phase introduces Kubernetes, Amazon Elastic Kubernetes Service (EKS), and database fundamentals for the microservices platform.

It covers Kubernetes architecture and core concepts, EKS cluster fundamentals, Amazon RDS, and database management in an EKS environment.

The objective is to understand how containerized applications are orchestrated using Kubernetes and EKS, and how application workloads connect to and manage their database dependencies.

## Objectives

- Understand Kubernetes architecture and fundamentals.
- Learn Amazon EKS and its cluster components.
- Understand Amazon RDS and managed database services.
- Understand database management in an EKS environment.
- Learn how Kubernetes workloads communicate with databases.
- Understand the relationship between application services, Kubernetes, and databases.

## Expected Outcome

After completing this phase, you should understand Kubernetes fundamentals, how Amazon EKS provides managed Kubernetes infrastructure, how Amazon RDS supports application data storage, and how databases are managed and integrated with workloads running in EKS.

These concepts provide the foundation for the caching, messaging, secrets management, and advanced Kubernetes implementation phases.
